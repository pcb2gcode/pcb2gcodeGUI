Test data for pcb2gcodeGUI.

- `example_board/` and `milldrill/`: Gerber and Excellon files from pcb2gcode's
  `tests/data/gerbv_example/example_board_new_default` and `milldrill_multi_step`
  (GPLv3, https://github.com/pcb2gcode/pcb2gcode), with pcb2gcodeGUI configuration files.
- `legacy/old_gui.millproject`: a configuration file in the format pcb2gcodeGUI 2.5.0 wrote.
- `pcb2gcode-3.2.0-help.txt`: `pcb2gcode --help` of the pcb2gcode 3.2.0 release.
